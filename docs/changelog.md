## 2026-07-29 — THE V4 PIVOT + the production canon (six hash-pinned documents)

**The pivot.** From "daily standalone stereotype reels" → a **curriculum-driven serialized story universe**: four characters pulled from their own worlds into Germany, taught across **A1→B1** in ~170 × 30-second episodes. Basis: four research docs Jayon supplied (narrative SLA design, DaF syllabus taxonomy, micro-learning cognition, story-ideation architecture) + twelve invideo production guides.

**The curriculum** (`CURRICULUM_v1_universe.md`, awaiting lock) — 3 levels × 10 modules × **164 teaching atoms**. Atoms are an *inventory*, not one-reel-each: at ideation a module (the story-arc unit, one lead character) gets a **block plan** packing 1–3 related atoms into universal **30-second blocks**. Casting = one spine, rotating lead. Canon: characters are **fluent-but-foreign** — bewilderment, not deficit, makes their speech simple.

**The production canon — six documents, each answering one question, all hash-pinned and `verify_canon` GREEN:**
- **`MISSION.md` v2.0** — rewritten. The old one was V2-era and *actively harmful*: injected into every call while describing "ten words → ten scenes → ten clips" and calling the cast "food-puppet characters" — a word `TREATMENT` bans. - **`SHOW_BIBLE.md` v1.1** — the universe and its people. Merges the four character bibles. **Every speech constraint deleted** per Jayon (grammar habits, "teaches: X", word budgets); Müller's belief reframed from *"Words are expensive"* to *"Feelings are private. - **`STORY_SYSTEM.md` v1.0** — how a scene comes into being. **Reverse scenario generation**: structure → the situation that naturally demands it → the scene, with the acceptance test *"would a real person here produce this more than once, unprompted?"* — if no, **change the situation, never bend the grammar**. ## 2026-07-24 (latest) — The Overseer ("Director") — always-present editor, BUILT

- **What it is.** A floating, minimizable **"Director" window** present on every studio step. You tell it what to change at any stage; it lands the edit at the right layer and shows you exactly what will recompile **before** anything changes. Realizes the vision in `DESIGN_story_ideation_and_overseer.md` Part B.
- **Mechanism = propose → confirm → apply** (deliberately NOT a free-form function-calling loop). `plan()` uses Gemini **structured output** (reliable) to produce a typed edit plan + a human diff; the app shows the diff + the **graph-computed recompile set** with Confirm/Cancel; only on confirm does `apply()` execute **deterministic Python** edits + the **targeted** downstream recompiles. The dependency graph — not the model — decides what rebuilds; every apply is a ledger event (best-effort). Guardrails: typed ops only, confirm-with-diff, ledger audit.
- **Dependency graph.** `brief → screenplay (LOCK) → storyboard sheets → Seedance prompts`. Edit a shot in segment K → recompile ONLY K's sheet-prompt + K's Seedance-prompt. Edit the brief → rebuild screenplay → all sheets + prompts.
- **Typed ops:** `edit_shot` (director-layer fields + dialogue), `rewrite_segment` (LLM re-gen of one segment's shots), `edit_brief` (dotted paths; full rebuild), `answer_only` (Q&A / clarify — it's also a monitor you can just ask).
- **New:** `pipeline/overseer.py` · `prompts/skills/skill-5-overseer.md` · `POST /api/overseer/{plan,apply}` · floating Director UI (FAB + panel + confirm-with-diff) in `index.html`; overseer `apply` returns the updated artifacts so the visible step refreshes **without** re-running the skills.
- **Verified LIVE (backend + UI):** "make segment 3 shot 2 warmer and Müller content" → PLAN proposed `edit_shot` (lighting_mood + expression) + recompile "screenplay 3 → sheet 3 → prompt 3" → CONFIRM → screenplay shot edited on disk (`Warm, cozy… golden`, `Content and deeply relieved`), sheet 3 + Seedance prompt 3 recompiled, **segments 1–2 byte-for-byte unchanged**, storyboard step auto-refreshed. Ledger-log failure is non-fatal (audit is best-effort).
