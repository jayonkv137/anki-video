## Learning log

- Covered (2026-07-22, V3 pivot): why per-scene (10-clip) generation drifts and Seedance's **native multi-shot** fixes it (fewer, longer, coherent clips); the **hash-pinned canon discipline** (edit → bump version → recompute SHA-256 → update REGISTRY → verify green — every time); **reshaping a data contract that ripples downstream** (do the schema + validators first, unit-test on synthetic pass/fail BEFORE writing the prose skills); **stereotype-first curriculum** (drop forced deck coverage; enforce CEFR caps + a declared grammar target instead); ingesting an external library as a **tracked, idempotent asset with a coverage log**; **mixed-initiative co-creativity** (divergent↔convergent gates, "Ask Don't Guess / Refine via Examples", reflective friction = human ownership); **anti-slop mechanics** (human-seed injection, per-stage temperature, banned-token + stereotype-name filters, self-critique); **modal particles** as a spoken-German curriculum; the UCB **"game of the scene"** micro-story grammar; and **authoring deep-research prompts** as a repeatable way to de-risk a stage before building it.
- Covered: PSB method, evidence-chained decisions, git/gh, Docker+n8n basics, Supabase/PostgREST, structured outputs + semantic validate→retry (incl. two real failure lessons: -eln stemming false positive, max_tokens truncation). NEW: RCP architecture (why stateless-with-shared-pack beats one-long-conversation), hash-verified canon (tamper detection), ledger-based run tracking (resumability + auditability), Gate A pattern (human choice before committing resources).
- Covered (2026-07-21): single-responsibility skill splitting (one behavior = one versioned file, so `/tune` owns exactly one place); model-tier routing (Haiku 4.5 for cheap strict quality-checks — the R10 rubber-stamping risk, the "fail if unsure" mitigation, and the one-line model-upgrade path once `_call` is parameterized); dual video-model prompt design (Seedance first-30-words law + ref-mirroring vs Omni narrative brief + stateful edit-turns); reference-asset role mapping and resolving canonical names → assets (umlaut folding) with honest `pending` for assets not yet produced (don't fabricate); structured-output JSON schema discipline (`additionalProperties:false` + all-required).
- Covered (2026-07-21, E6): the "16k+ max_tokens" truncation lesson recurring at a new output shape (dual packages need proportionally more room — always re-check the ceiling when an output shape grows); a cost-tracking bug that was silently 10x wrong for months (E3-era code) — cents-per-token math is easy to get an order of magnitude wrong; per-model-tier pricing (don't apply Sonnet rates to Haiku calls); why `choose`/`resume` must reload by exact word positions, not re-fetch sequentially, once `--random` runs exist.
- Covered (2026-07-21, visual pivot): semantic poisoning — aesthetic vocabulary in a style block steers the whole latent space (old canon's "puppet/felt" words CAUSED seams/stop-motion looks; purge + AVOID-list both needed); Constants-vs-Variables prompt architecture (immutable medium/material/negative laws vs per-scene lighting/DoF written by the LLM-as-DP — the fix for "pasted-in" characters); PBR material vocabulary as identity control (IOR, subsurface scattering, albedo, ambient occlusion, displacement, anisotropic shading); multi-angle character sheets beat portraits for video refs (structural map prevents back/side dissolution); budget accounting when placeholders expand post-generation (LLM can't see final length — tell it the expansion cost).
